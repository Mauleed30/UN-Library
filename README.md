# UN-Library - University Repository Management System

A comprehensive platform for managing academic submissions, theses, dissertations and research papers.

## ✨ Features

- 🔐 **Authentication** - Login, Register, Forgot Password
- 👥 **Role-Based Access** - Student, Faculty, Librarian, Admin
- 📝 **Document Submission** - Upload, Review, Approve, Publish
- 📚 **Public Catalogue** - Browse and Search published works
- 📊 **Analytics Dashboard** - Statistics and Reports
- 📁 **File Upload** - PDF, DOC, DOCX
- 📱 **Mobile Responsive** - Works on all devices

## 🛠️ Technologies

| Layer | Technology |
|-------|-----------|
| Backend | Laravel 9, PHP 8.2 |
| Database | MySQL |
| Frontend | Blade, Bootstrap 5, JavaScript |
| Tools | Composer, Git, XAMPP |
